关键语义修复包括：

- `prim.c` 用 `INF` 表示无边，真实零权边可参与松弛；C++/Python 用 `(weight, vertex, parent)` 区分根种子与真实零权边。

- `hash_probe.cpp` / `.py` 改用 `std::optional` / `None` 槽，`-1` 成为合法键。
- `bplus_tree.c` 从 72 槽静态池改为几何扩容的节点表，新增 500 键动态增长用例。
- `bst.c` / `avl_tree.c` 通过 `failed` 标志传播分配失败，父结点不再把已有子树写成 NULL。
