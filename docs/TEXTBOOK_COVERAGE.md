# 教材课程覆盖表

知识体系与章节顺序以严蔚敏、吴伟民《数据结构（C语言版）》（清华大学出版社，1997 年 4 月第 1 版）为主要参考；通俗讲解与典型应用选材参考程杰《大话数据结构（溢彩加强版）》（清华大学出版社，2020 年修订版）。两本书的章节、印刷页与 PDF 页索引见 [`REFERENCE_BOOKS.md`](REFERENCE_BOOKS.md)。

## 教材使用原则

- 12 章作为一级大纲，保持教材的知识推进顺序；章名允许按课程表达需要做小范围优化，不机械照抄目录。
- 二级、三级目录按知识关系组织，而不是按“理论/动画”分栏。分组可以继承理论页、可视化课程或两者混合；只有存在明确从属课程时才建立三级叶子，不为凑层级制造单子项分组。
- 理论内容用静态结构图、对照表和文字完整讲解；只为有独立教学价值的操作或算法提供逐帧播放器。
- 不要求把教材中的每个应用实例都做成动画。数制转换、行编辑、迷宫求解、括号匹配等只在相关理论页中作为简短例子，不设独立课程占位。
- 稳定的算法 ID、概念 ID、路由与学习状态不随目录改名而改变。

## 第 3 章覆盖明细

教材体系以严蔚敏《数据结构（C语言版）》为准；程杰《大话数据结构》只用于补充经典应用的选材与入门解释，不改变本章的 ADT 定义、存储约定和算法主流程。

| 小节 | 理论专题 | 动态课程 | 覆盖要点 |
| --- | --- | --- | --- |
| 3.1 栈 | `stack-queue-storage` | `stack` | 后进先出、栈顶与栈底、顺序栈 `top = -1` 空栈约定、链栈首结点、push/pop/peek 的真实 Trace |
| 3.2 栈的应用举例 | `stack-recursion` | `infix-to-postfix`、`postfix-eval` | 运算符优先级与括号边界、中缀转后缀、后缀操作数栈求值、向零截断整数除法 |
| 3.3 队列 | `circular-queue`、`stack-queue-storage` | `queue` | 先进先出、循环队列“牺牲一个单元”判空判满、`front`/`rear` 回绕、带头结点链队列 |
| 3.4 栈与递归 | `stack-recursion` | `factorial`、`fib` | 递归调用栈的活动记录、返回地址与局部变量、递归深度；复用既有递归动画，不重复实现 |

本章的 `stack` 与 `queue` 各用一个播放器覆盖两种存储实现，通过输入区的 storage 选择器切换：

- `stack` 支持 `array`（顺序栈）与 `linked`（链栈），默认容量 4，真实展示 `top`、`nodes`、`topId` 和容量边界。
- `queue` 支持 `circular`（循环队列）与 `linked`（链队列），默认容量 5，循环队列最多存 4 个元素；真实展示 `front`、`rear`、回绕 `wrap` 与队满 `full` 步骤。
- 链队列采用带头结点约定：空队列时 `front == rear == head`；删除最后一个数据结点后 `rear` 回到 `head`。原先作为计划占位的 `chain-queue` 专题已删除，由 `queue` 的 `linked` 存储模式覆盖，不再保留重复入口。

`infix-to-postfix` 与 `postfix-eval` 是栈应用唯一新增的两个经典动画。数制转换、括号匹配、行编辑、迷宫求解、离散事件模拟等教材举例不再拆成独立可视化入口，只在栈应用理论页中作为简短说明。两者与 `stack` 共享“栈”这一结构语义，但使用独立的表达式 Trace Schema，避免用结构操作帧伪造算法步骤。中缀转后缀官方示例为 `(3 + 4) * 2 → 3 4 + 2 *`；后缀求值官方示例为 `3 4 + 2 * → 14`。两者强制以 Python 作为导学与官方执行语言，同时保留 JS 预置程序供切换。

## 第 5 章覆盖明细

本章继续以严蔚敏《数据结构（C语言版）》的数组、压缩存储、广义表顺序为准；程杰《大话数据结构》只补充“二维数组即线性表”“广义表像嵌套括号”的直观解释。第 5 章没有把教材所有例题拆成动画：数组地址计算、特殊矩阵映射、广义表定义与存储、m 元多项式结构使用静态图或轻量交互图完整教学，只有“快速转置”“求深度”“复制”三门需要逐帧观察递归或下标变化的算法进入动态课程。

| 小节 | 理论专题 | 动态课程 | 覆盖要点 |
| --- | --- | --- | --- |
| 5.1 数组的定义 | `array-basics` | — | 一维/多维数组、元素与下标、维数与各维长度、数组是下标受限的线性表；3×4 交互图同时展示二维逻辑位置与一维连续内存 |
| 5.2 数组的顺序表示和实现 | `array-basics` | — | 行优先/列优先切换、0 基下标约定、`base=1000`、`w=4` 字节、`A[1][2]` 行优先 1024 / 列优先 1028；公式与图上高亮单元一致 |
| 5.3 矩阵的压缩存储 | `special-matrices`、`sparse-matrix` | `sparse-transpose` | 对称矩阵只存下三角并由 `i≥j` 对称恢复；上/下三角常量区共用一格；三对角只存三条对角线；稀疏矩阵三元组 `(row, col, value)` 行优先、非零计数与存储代价 |
| 5.4 广义表的定义 | `generalized-list` | — | 原子/子表/空表、长度只数最外层、深度按嵌套层数、表头为首元素、表尾为删首元素后的表；`()` 与 `(())` 的差别、递归定义、与普通线性表的区别 |
| 5.5 广义表的存储结构 | `generalized-list-storage` | — | `tag` 区分原子与子表、原子存 `atom`、子表 `hp` 指向首元素、`tp` 指向同层后继；表头—表尾链与逻辑嵌套的对应，明确不是二叉树 |
| 5.6 m 元多项式的表示 | `m-variable-polynomial` | — | 一元多项式按指数有序链（第 2 章）与 m 元多项式“项表套因子表”的层次结构；常数项无变量因子；不新增多元加减乘除动画 |
| 5.7 广义表的递归算法 | — | `gl-depth`、`gl-copy` | 原子返回 0、空表返回 1、非空表取子表最大深度加 1；复制先分配新节点再递归子表，副本结构与源等价但节点完全独立；真实 Python 递归 Trace、调用栈、回退与跳帧 |

本章新增 `gl-depth`、`gl-copy` 两门动态课程，共用表达式解析器、输入编辑器、树布局与播放器。输入仅接受括号、逗号、字母数字下划线原子，根必须是表；限制 80 字符、40 节点、最大嵌套深度 8。深度约定为“原子 0、空表 1、非空表 `1 + 子表最大深度`”，默认 `(a, (b, c), ((d), e))` 深度 3，`(())` 深度 2。复制采用先序构造：先为新节点分配编号并接入新父节点，再递归复制各子表；画布用 `c0…` 与源 `n0…` 对应。循环引用、自引用和任意共享子结构不在输入模型内，解析阶段直接拒绝。

`sparse-transpose` 复用原有课程，不重复开发。其真实 Python 入口已是快速转置：先按列统计 `num[c]`，再由 `cpot[c] = cpot[c-1] + num[c-1]` 递推每列在结果三元组表中的起始槽，最后一遍扫描源三元组直接写入目标位置，时间 `O(t+c)`、额外空间 `O(c)`。

### 四种存储结构的图解

- **邻接矩阵**：左侧同一张无向图 `A–B, A–C, B–D, C–D`，右侧 4×4 矩阵。高亮边 `B–D` 时只同步高亮 `A[B][D]` 与 `A[D][B]`；矩阵对称、有向图不必对称、带权图用哨兵区分“无边”和“零权边”、自环落在对角单元、空间 `O(V²)`。
- **邻接表**：同一张图 `n=4, e=4`，无向边在两端各登记一次，共 8 个边结点；明确顶点表、边结点 `adjvex`/`next`、权值域，以及有向图只挂出边、逆邻接表互补的关系。边结点数按方向语义区分 `e` 与 `2e`，空间 `O(V+E)`。
- **十字链表**：有向图 `e1 A→B, e2 A→C, e3 B→C, e4 C→A`。顶点节点含 `firstin`/`firstout`，弧节点含 `tailvex`/`headvex`/`hlink`/`tlink`；同一条弧只存一个节点，同时进入起点出链与终点入链。图解按字段逐条核对链关系，不把 `tlink` 与 `hlink` 混用。
- **邻接多重表**：无向图 `e1 A–B, e2 A–C, e3 B–C, e4 C–D`，每条边只有一个边节点，含 `ivex`/`jvex`/`ilink`/`jlink`，顶点节点含 `firstedge`。`e3` 同时属于 B 的链（`ivex=B`）与 C 的链（`jvex=C`），用于说明“一个边节点被两个端点链引用”，而不是画成邻接表的两个副本。
- **对比表**：覆盖邻接矩阵、邻接表、十字链表、邻接多重表的适用图型、空间复杂度、边记录数、查边 `(u,v)`、枚举邻居和最适合场景，解释同一张图为何可以有不同的物理组织。

### 复杂度口径

| 模块 | 时间 | 空间 | 变量与说明 |
| --- | --- | --- | --- |
| 空闲表 | `O(M · F)` 最坏 | `O(F + B)` | M 操作数、F 空闲块数、B 总块数；首次适应可提前停止，最佳适应通常要扫描完空闲表；有序表可按地址找邻块，但插入/删除仍有表操作 |

### 分块查找

- 数据不重排；块是原数组上的连续区间，索引项记录每块真实最大值、起点和长度。
- 采用的索引约束是：块最大值严格递增，且后一块的所有关键字都大于前一块最大值；块内允许无序。输入校验失败时拒绝执行并显示双语错误，不会为了“满足条件”而静默排序。
- 查找先顺序扫描索引，进入第一个满足 `max >= target` 的块，再在该块内顺序扫描；目标大于所有索引最大值时直接失败，不进入任何块。
- 真实 Python Trace 分为 `index-compare`、`index-select`、`block-compare`、`found/not-found` 等阶段，分别记录索引比较次数和块内比较次数。官方、自定义和随机输入共用同一播放器；随机场景覆盖中间块命中、块间空隙失败、末块命中、边界关键字、首块命中和全表失败。

### B 树删除

- 沿用现有 4 阶 B 树：每节点最多 3 个关键字、4 个孩子；非根节点至少 1 个关键字，根可为叶，所有叶同深度。
- 删除前先证明关键字存在；不存在时只回放只读搜索，树保持不变。存在时采用自顶向下预修复：下降前保证将进入的孩子关键字数足够。
- 孩子不足时先向左兄弟借，再向右兄弟借；两侧都不够则父关键字下移并与兄弟合并；合并可能继续向上传播；根被抽空时唯一孩子成为新根。
- 内部关键字删除用左子树最大前驱替换，再在叶层删除前驱；若预修复已使目标键下移，则改为在合并后的孩子中继续删除目标键，避免把旧键遗留在叶中。主图始终按真实节点、父子链接和键序重绘，不靠删文本假装删除。
- 六个官方场景分别覆盖叶节点普通删除、内部键替换、左/右借位、合并、根收缩和删除不存在关键字；多次连续删除由自定义输入承担。Schema 校验节点容量、键序、子树范围、叶深度一致性和根的特殊约束。

### B+ 树核心操作

- 沿用 4 阶约定：每节点最多 3 个关键字；内部节点 `k` 个键对应 `k + 1` 个孩子；记录只存在叶节点，内部键只是右子树最小记录的分隔键；叶节点用 `next` 顺序链接。
- 点查找沿分隔键下降到唯一叶节点后再比较记录；插入只写叶节点，叶分裂按 2/2 分配并提升右叶首键，内部节点分裂提升并移除中间分隔键，根分裂创建一层新索引；范围查询从下界叶开始，沿 `next` 前进直到超过上界。
- 分隔键在分裂和根增长后按最终树重新定位，Trace 中的父节点、提升键和范围路径均以真实结构为准；重复关键字在修改前拒绝。
- **本轮覆盖范围明确为查找、插入、叶/内部/根分裂与范围查询，不包含 B+ 树删除。** 课程文案、流程图和参考代码均按此声明，不虚报未实现的操作。

### 键树

- 每个字符对应一条边和一个节点；哨兵根不表示字符，`terminal` 标记某个前缀是否为完整关键字；共享前缀共用节点。
- 查找逐字符下降并记录已匹配长度；只有整条路径存在且末节点 `terminal=true` 才算命中，仅有前缀不算单词。插入先拒绝重复，再只为缺失后缀建节点，最后设置终止标记。
- 输入限定为小写 ASCII 单词、长度 1–8、最多 8 个词；官方词表为 `car, card, care, cat, dog, do`，覆盖共享前缀命中、前缀非单词、缺失分支、共享前缀插入、新分支插入和前缀插入。
- 键树只承担字典/前缀结构教学，不扩展成自动补全、搜索引擎或大规模文本应用。

### 复杂度口径

| 结构 | 查找 | 插入/删除 | 条件与备注 |
| --- | --- | --- | --- |
| 顺序查找 | `O(n)` | 静态表通常不讨论 | 无序或有序均可；ASL 取决于命中概率 |
| 二分查找 | `O(log n)` | 静态有序表不适用 | 必须有序且支持随机访问；判定树高度约 `⌈log₂(n+1)⌉` |
| 分块查找 | `O(b + s)`，块长约 `√n` 时 `O(√n)` | 静态索引结构 | `b` 块数、`s` 块长；需块间有序、块内可无序 |
| BST | 平均 `O(log n)`，最坏 `O(n)` | 平均 `O(log n)`，最坏 `O(n)` | 取决于树高与插入顺序，不保证平衡 |
| AVL | `O(log n)` | `O(log n)` | 严格平衡，旋转维护高度差 |
| B 树 | `O(log_m n)` | `O(log_m n)` | `m` 为阶；节点容量与最小关键字约束决定磁盘访问次数 |
| B+ 树 | 点查 `O(log_m n)`；范围 `O(log_m n + k)` | 插入 `O(log_m n)`；删除本轮未实现 | 记录只在叶层，范围查询沿叶链扫描 `k` 条记录 |
| 哈希表 | 平均 `O(1)`，最坏 `O(n)` | 平均 `O(1)`，最坏 `O(n)` | 依赖哈希函数质量、装填因子与冲突策略；开放定址删除需墓碑 |
| 键树 | `O(L)` | `O(L)` | `L` 为关键字长度；空间与字符节点数相关，共享前缀可减少节点 |

以上数值均附条件，不用单一排名宣称某种结构对所有任务最优；内查找与外查找的差异在比较页单独说明。
