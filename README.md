# AlgoViz · 数据结构与算法可视化学习平台

**在线使用：https://vvvi734.github.io/AlgoViz/**

AlgoViz 是一个面向数据结构与算法课程的交互式学习网站。教材目录、算法动画、逐帧执行、教学导学和多语言参考代码都放在同一个网页里，适合课堂演示、自学和复习。

当前正式版本：**v1.0.0**　·　[GitHub Release](https://github.com/vvvi734/AlgoViz/releases/tag/v1.0.0)　·　[项目源码](https://github.com/vvvi734/AlgoViz)

## 网站功能

### 按教材章节学习

- 按 12 章教材体系组织课程，从绪论、线性表、树、图一直覆盖到查找、排序和文件。
- 左侧目录支持章节、专题、课程三级展开，当前位置自动高亮。
- 理论专题提供中英文正文和静态图解；动态算法提供可播放的执行动画。
- 支持亮色、深色和跟随系统三种主题。

### 看算法一步一步执行

- 每个动态算法都有时间轴，可播放、暂停、逐帧前进或回退，也可直接拖动到任意帧。
- 画布、变量、调用栈、执行步骤和参考代码共用同一个播放位置。
- 键盘快捷键：`←` 上一帧、`→` 下一帧、`↑` 重置、`↓` 末帧、`Space` 播放/暂停。
- 可进入全屏查看；支持缩放、平移和适应屏幕，图形放大时文字字号保持稳定。
- 移动端和窄屏下也能使用，避免横向溢出。

### 用自己的数据运行

- 每个算法提供官方示例、自定义输入和随机输入。
- 修改输入后重新生成，动画会根据当前数据重新执行。
- 输入不合法时给出提示，不会继续播放旧结果。
- 执行结果包含真实的帧记录、变量变化和数据结构快照。

### 算法导学与流程说明

- 每个算法配有导学，说明适用场景、核心思想、复杂度和易错点。
- 用自然语言描述算法流程，不要求先读伪代码。
- 当前步骤会与实际执行帧同步，方便把“代码怎么写”和“过程怎么走”对应起来。

### 三种语言参考代码

- 每个算法提供 C、C++、Python 三种只读参考实现。
- 参考代码带有中英文教学注释，可整段复制。
- 切换界面语言时，代码注释同步切换。
- C/C++ 仅在网页中展示，不在浏览器内编译执行。

### 中英文双语

- 教材正文、理论专题、算法名称、界面控件和参考代码注释均支持中英文。
- 语言切换不会重置当前算法或播放位置。

## 使用方式

1. 从左侧目录选择章节或算法。
2. 阅读算法导学，了解思路和复杂度。
3. 保留官方示例，或输入自己的数据、生成随机数据。
4. 播放动画，配合逐帧操作观察变量和数据结构变化。
5. 展开参考代码，对照 C、C++、Python 实现。
6. 需要课堂展示时进入全屏，使用快捷键控制播放。

## 执行说明

- Python 在浏览器内通过 Pyodide 执行，算法帧来自真实运行记录。
- 60 个官方输入均有有效帧记录；其中 59 个算法使用真实 Python Trace，`bubble` 官方入口使用明确标注的 25 帧 JavaScript 教学预设。`bubble` 的自定义和随机输入仍执行真实 Python。
- 首次运行 Python 需要从 CDN 加载 Pyodide，受网络和缓存影响；之后的执行在本地浏览器中完成。
- 所有计算都在本地浏览器进行，不需要服务器或数据库。

## 浏览器要求

建议使用较新的 Chrome、Edge 或其他支持 WebAssembly、Web Worker 和 ES2020 的浏览器。首次加载 Python 运行环境时需要联网。
