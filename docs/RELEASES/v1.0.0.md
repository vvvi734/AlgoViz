# AlgoViz v1.0.0

**首个正式版本（发布候选，等待发布确认）**

AlgoViz 是浏览器端的数据结构与算法可视化教材。Python 在 Pyodide 中真实执行，动画帧来自执行时记录的真实 Trace；`bubble` 官方课堂入口保留既有的 25 帧 JavaScript 教学预设。画布、变量、调用栈、课程步骤和参考代码共享同一个播放位置。

## 主要内容

- 12 章数据结构与算法学习体系，目录按章、专题、课程三级组织。
- 60 个动态算法，覆盖排序、查找、树、图、串、存储管理与文件结构。
- 56 个理论专题，提供中英文正文、静态图或轻量交互图。
- 真实 Python Trace 与逐帧动画；支持播放、暂停、单步、回退和跳帧。
- 60/60 动态算法支持官方示例、自定义输入与随机合法输入。
- 60/60 的自定义与随机输入执行真实 Python；59 个官方入口使用真实 Python Trace。
- `bubble` 官方课堂入口保留既有的 25 帧 JavaScript Trace，自定义与随机输入仍执行真实 Python。
- 60/60 提供 C、C++、Python 三语言只读原理参考代码，共 211 个 `.c` / `.cpp` / `.py` 源文件。
- 中英文双语界面、课程正文与代码内部教学注释；复制代码时包含当前界面语言对应的注释。
- 算法导学、声明式算法流程图、数据结构画布与响应式学习页面。

## 当前边界

- 不提供自由 Python 或 JavaScript 编辑器。
- 不提供在线 C / C++ 编译；参考代码只读，可复制到本地编译或运行。
- 部分课堂官方示例使用预设教学 Trace；自定义和随机模式执行真实 Python。
- B+ 树删除等部分非当前教学核心操作尚未单独可视化。
- 不包含全部教材应用实例的独立动画；普通例题在相关理论页说明。
- 需要支持 WebAssembly、Web Worker 和现代 ES2020 的浏览器；首次启动需从 jsDelivr 加载 Pyodide，受网络与缓存影响。

## 安装与运行

要求 Node.js 20 或更高版本：

```sh
npm ci
npm run dev
```

生产构建与本地预览：

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

构建输出为 `dist/`。这是纯静态站点，不需要数据库或后端服务；部署要求、子路径、缓存、CSP 和 Pyodide 资源说明见 [部署说明](../DEPLOYMENT.md)。
