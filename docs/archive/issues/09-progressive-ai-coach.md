# Issue 09 — AI 助教渐进式教学与防剧透

**Labels:** `ai, phase-3, todo`
**状态:** 待实现
**依赖:** Issue 05, 08

## 背景

当前只在 prompt 里写「不要给完整答案」，没有结构约束，也没有质量验证。

## 范围 / 实现要点

- 结构化响应：`diagnosis`、`hintLevel`、`leadingQuestions`、`nextSmallStep`、`codeExcerpt`、`confidence`。
- Level 1 引导思考 → Level 2 指出错误区域 → Level 3 给伪代码 → 只有用户明确要求时才给完整答案（Level 4）。
- 服务端保存密钥、最小化上报数据、校验模型输出不含完整解；前端逐级展示且不可跳级剧透。
- 用错误代码 fixture（如写坏的双指针）检验提示质量。

## 明确不做

- 不在前端存放 API key；不把完整答案偷偷塞进 `codeExcerpt`。
- 不把 AI 输出当作可直接执行的代码。

## 验收标准

- Level 1–3 的响应中检测不到完整可运行解；错误双指针代码能得到具体可验证的建议。
- 用户显式请求完整答案后才出现 Level 4，且有二次确认。

## 验证方式

提示质量 fixture 测试 + 响应结构校验单测
