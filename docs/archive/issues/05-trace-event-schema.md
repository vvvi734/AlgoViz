# Issue 05 — 统一 Trace Event Schema v1 与跨语言适配器

**Labels:** `protocol, phase-2, todo`
**状态:** 待实现
**依赖:** Issue 03, 04

## 背景

四种语言目前各自输出 `frames[{state,message}]`，无版本、无校验、无字段约束。

## 范围 / 实现要点

- 定义版本化事件协议（`schemaVersion`、事件类型、状态类型枚举、帧上限、长度上限、`line`/`column` 源码定位）。
- 提供运行时校验器（拒绝非法/超大帧）与 JS / Python / C / C++ 四种 emitter 约定和文档。
- 回放引擎只消费校验后的事件，支持播放、暂停、回退、单步、跳转，且完全不依赖代码执行。
- 为冒泡排序、BFS、链表操作提供 fixture 驱动测试。

## 明确不做

- 不改变可视化的教学语义，不引入后端依赖。
- 明确区分「已支持的事件类型」与「占位类型」。

## 验收标准

- 所有 fixture 可确定性渲染并可脱离执行器回放。
- 非法帧、超长数组、超量帧被拒绝且给出可读错误。

## 验证方式

`src/domain/trace/schema.test.ts`（新增）+ 现有动画回归测试继续通过
