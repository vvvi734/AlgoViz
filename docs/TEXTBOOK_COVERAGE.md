## 课程状态说明

- **动态算法**：37 个入口均有真实 Python Trace、输入 Schema、官方/自定义/随机输入、单一播放器、变量与调用栈、算法导学与流程图，以及 C / C++ / Python 三语言双语注释参考代码。
- **理论专题**：28 页均为静态教学页，含中英文正文和至少一张静态图，没有播放器或编辑器。
- **扩展内容**：冒泡排序不在教材正文顺序中；阶乘/斐波那契用于演示递归调用；Bellman-Ford 是对最短路径章的补充。三者保留并在目录中标记为扩展。
- **计划知识点**：上表“待后续开发”共 26 项，只显示目录占位，不提供动画或课程；实现时应按“新增动态算法”流程接入，不能把占位改成伪造 Trace。
- **特殊位置**：KMP 归属第 4 章“串”，稀疏矩阵快速转置归属第 5 章“数组和广义表”，不是扩展入口。
