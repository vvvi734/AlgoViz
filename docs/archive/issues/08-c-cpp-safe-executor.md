# Issue 08 — C/C++ 安全编译执行后端（隔离沙箱）

**Labels:** `backend, security, phase-2, todo`
**状态:** 待实现
**依赖:** Issue 05

## 背景

C/C++ 当前只有示例与 `/api/execute` 协议，仓库不提供服务；绝不能在普通 Web 服务进程运行不可信代码。

## 范围 / 实现要点

- 独立的、经过认证的、带速率限制的执行服务，优先复用成熟判题/沙箱基础设施。
- 强制：无网络、只读文件系统、CPU/内存/时间/输出上限、进程数限制、编译错误结构化返回。
- 解析并校验 `TRACE ` 前缀输出，绝不盲信 stdout；与 Trace Event Schema v1 对齐。
- 前端补充连接状态、错误分类与「未配置后端」的明确提示。

## 明确不做

- 不在 Web 服务进程内 `system()` 编译或执行用户代码。
- 不在前端暴露沙箱凭据。

## 验收标准

- 正常 C11 / C++17 程序通过；死循环、超大输出、编译错误、危险系统调用、内存超限均安全失败。
- 集成测试覆盖以上五类攻击样例。

## 验证方式

后端集成测试（C11 / C++17）+ 前端契约测试
