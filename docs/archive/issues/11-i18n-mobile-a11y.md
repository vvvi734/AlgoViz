# Issue 11 — 中英文界面完善、移动端适配与可访问性

**Labels:** `i18n, a11y, phase-3, todo`
**状态:** 待实现
**依赖:** Issue 02, 06

## 背景

现有中英词典覆盖基础界面，移动端只是断点堆叠，未做系统性的可访问性验证。

## 范围 / 实现要点

- 补齐所有动态文案（错误、加载、空态、编辑器诊断、题库分类）的中英词条，词典键 parity 由测试保证。
- 移动端：时间轴控件、代码区、题库卡片、弹窗的触控尺寸与横向溢出治理。
- 键盘导航、焦点可见、ARIA 标签、对比度（含两套主题）、`prefers-reduced-motion`。

## 明确不做

- 不以缩小字体换取紧凑；超长标题换行而非截断。

## 验收标准

- 两套主题下文本对比度达标；主要流程可全键盘完成。
- 375px 宽度下无横向滚动，控件可点。

## 验证方式

axe 可访问性扫描 + 移动端视口测试（Issue 12）
