# Archive

This folder preserves historical delivery reports and screenshot evidence. It is **not** current product documentation and does not describe the shipped feature set.

## Contents

- `reports/` — stage and feature reports written before TEXTBOOK-01. Some describe AI Gateway, MCP, knowledge packs, practice questions, or the old editable Monaco workflow; those features have been removed and the reports are kept only as project history.
- `issues/` — the original 14-issue planning list, superseded by the current textbook plan.
- `evidence/` — historical screenshots linked from the reports. No current test or build reads them.

The current README and architecture document are authoritative whenever an old report disagrees with the code.
