# Issue 06 — 代码编辑器：语法高亮 / 行号 / 编译错误提示 / 代码保存

**Labels:** `editor, phase-2, todo`
**状态:** 待实现
**依赖:** Issue 02, 05

## 背景

当前仍是纯 textarea，四语言无高亮、无诊断、无持久化代码。

## 范围 / 实现要点

- 引入零后端依赖的编辑器（CodeMirror 6 或 Monaco），语言包覆盖 C++17 / C11 / Python / JavaScript。
- 行号、括号匹配、缩进、主题与 `--code-*` 令牌完全对齐 Light/Dark/System。
- 编译/运行错误映射到行列并在编辑器中标注；错误文案中英双语。
- 代码保存：按「算法 × 语言 × 题目」键持久化到 localStorage，提供显式「保存 / 恢复示例 / 另存」与导入导出。

## 明确不做

- 不把用户代码上传到任何服务器（除非显式点击运行）。
- 不在编辑器里内置密钥或调用模型厂商直连接口。

## 验收标准

- 四语言高亮可见；主题切换后编辑器配色随之变化且对比度达标。
- 语法错误能定位到行列；保存后刷新页面代码仍在。

## 验证方式

编辑器组件单测 + 主题令牌一致性测试 + Playwright（Issue 12）
