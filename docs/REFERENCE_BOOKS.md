## 8. 使用规则

1. **严是范围基准**：新增理论专题、补目录、判断知识点是否属于教材范围时，以严的章节和术语为准。
2. **大话是解释参考**：需要类比、图示或更口语化的引入时查大话；不要照搬它的段子和正文。
3. **引用格式**：`[严 1997, §9.2.1, 印刷 p227 / PDF p237]` 或 `[大话 2020, §8.7, 印刷 p273 / PDF p302]`。
4. **大话必须回看页面**：它是扫描 OCR，检索结果有错字；涉及公式、代码、页码时以渲染出的页面图像为准。
5. **不复制教材内容**：只提炼知识点、术语、复杂度和算法流程；课程文案、图示、Trace 和参考代码继续由项目重写。
6. **新增课程时更新索引**：如果新增的专题在两本书中有明确章节，补进本文件第 6 或第 7 节，并同步 `reference-books/index.json`。

## 9. 后续开发的资料顺序（建议，不代表已排期）

1. **先补两本都有图示的短专题**：链队列（严 §3.4.2 / 大话 §4.13）、栈的应用（严 §3.2 / 大话 §4.8–4.9）。这两项能直接衔接现有栈、队列课程，参考资料也最完整。
2. **再补严有、大话无但规模可控的专题**：一元多项式（严 §2.4）、基数排序（严 §10.6）、排序方法比较（严 §10.7，大话 §9.10 可辅助对比表）。
3. **最后处理只在严中的大块内容**：广义表与 m 元多项式（严 §5.4–5.6）、回溯法（严 §6.7）、动态存储管理（严第 8 章）、外部排序与文件（严第 11–12 章）。这些内容缺少大话的直观材料，开发前应先补静态图和术语页，不应直接做动态 Trace。
4. **暂不优先**：文件章和外部排序涉及外存模型，当前项目没有对应运行时；先保留目录占位，等输入与 Trace 模型明确后再做。

## 10. 页面渲染

需要核对扫描页时，用 PyMuPDF 渲染成图片再读：

```powershell
python -c "import pymupdf; d=pymupdf.open('大话数据结构.pdf'); d[301].get_pixmap(matrix=pymupdf.Matrix(2,2)).save('page-302.png')"
```

上面命令中的 `d[301]` 是 PDF 第 302 页，即大话 §8.7 的起始页。严蔚敏版同理，只改文件名和页索引。
